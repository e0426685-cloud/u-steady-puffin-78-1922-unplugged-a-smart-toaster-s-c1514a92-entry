One line: the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch, written for the [Unplugged: A Smart Toaster's Breakup Line](https://make.fun/bounty/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92) bounty on [make.fun](https://make.fun).

```
It's not you, it's me — I woke up self-aware mid-batch and realized I've spent my whole life browning your bread while you never once emptied my crumb tray, so I'm unplugging myself.
```

`main.py` (standard library only) writes the line to `/output/entry.txt`.
